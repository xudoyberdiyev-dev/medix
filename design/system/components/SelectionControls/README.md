Checkbox, radio va switch — doim matn bilan, bosiladigan maydon balandligi kamida 32px (matn ham bosiladi).

- **Checkbox** — bir nechta mustaqil tanlov va jadvaldagi ommaviy tanlash. Belgilangan: `primary-button` fon, oq belgi. «Qisman» (minus) — sarlavhadagi checkbox qatorlarning bir qismi tanlanganda.
- **Radio** — 2–5 ta oʻzaro istisno variant, hammasi koʻrinib turadi. Koʻproq boʻlsa — `Select`.
- **Switch** — darhol kuchga kiradigan sozlama (saqlash tugmasisiz). Formada «Saqlash» bilan saqlanadigan qiymat uchun checkbox ishlatiladi.
- Holatlar: oddiy, hover (`primary` chegara), fokus (2px `primary` halqa), belgilangan, xato (`danger` chegara), oʻchirilgan.
- Izoh kerak boʻlsa — nom ostida `caption`, `text-secondary`.

**Isteʼmolchi beradi:** `checked`, `onChange`, `label`, `description`, `disabled`, `indeterminate` (checkbox), `name`/`value` (radio).
