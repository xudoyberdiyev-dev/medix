Ogohlantirish bloki sahifa ichida, tegishli joyda turadigan xabar: ikonka + sarlavha + matn + ixtiyoriy tugma.

- **Tonlar:** success, warning, danger, info. Fon `*-bg`, ikonka (20px), sarlavha (`600`) va matn — shu tonning toʻq rangi (`success`, `warning`…), qora emas.
- Chegara va rangli chap chiziq yoʻq; `radius-card`, `space-12`/`space-16` chetlar.
- Tugma ixtiyoriy, bitta, ikkinchi darajali (`sm`): «Qayta urinish», «Partiyalarni koʻrish».
- Sarlavha — nima boʻldi; matn — nima qilish kerak. Texnik kodlar («Xato 500») koʻrsatilmaydi.
- Holat oʻtguncha turadi (toast kabi yoʻqolmaydi). Danger uchun `role="alert"`, qolganlari `role="status"`.

**Isteʼmolchi beradi:** `tone`, `title`, `children` (matn), `action?`, `icon?` (standart tonga qarab).
