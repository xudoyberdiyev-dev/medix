Sahifalash jadval ostida turadi va qaysi qatorlar koʻrinayotganini aytadi.

- Chapda: `1–50 / 1.240` (sonlar `tabular-nums`, minglar nuqta bilan — tizimning raqam formati).
- Oʻrtada: «Sahifada:» + 25 / 50 / 100 tanlovi (standart 50). Tanlov foydalanuvchi uchun eslab qolinadi.
- Oʻngda: oldingi/keyingi (faqat-ikonka, tooltip bilan), sahifa raqamlari; joriy sahifa `primary-soft` fonda `primary-button` matn. 7 dan ortiq sahifada oʻrtasi `…` bilan qisqaradi.
- Bitta sahifaga sigʻsa ham son koʻrsatiladi («1–37 / 37»), raqamlar yashiriladi.

**Isteʼmolchi beradi:** `page`, `pageSize`, `total`, `onPageChange`, `onPageSizeChange`, `pageSizeOptions` (standart `[25, 50, 100]`).
