Yon panel jadvaldan chiqmasdan yozuvni koʻrish yoki tahrirlash uchun oʻngdan ochiladi.

- Kenglik: 480px (`drawer-sm`, koʻrish) yoki 640px (`drawer-lg`, tahrirlash). Toʻliq balandlik, `surface`, chapda 1px `border`, `shadow-overlay`, orqada `overlay`.
- Sarlavha: kichik turi («Partiya»), nomi (`subtitle`), raqami (`mono`) va holat badge'i; oʻngda yopish (x).
- Ixtiyoriy tablar, keyin aylanadigan tana (`space-24`), pastda doim koʻrinadigan harakatlar (asosiy oʻngda).
- Jadvalda bosilgan qator `primary-soft` boʻlib qoladi — qaysi yozuv ochilgani koʻrinsin.
- Saqlanmagan oʻzgarish bilan yopilsa — «Saqlanmagan oʻzgarishlar» tasdiqlash oynasi.
- Esc yopadi; fokus panel ichida; yopilganda jadval qatoriga qaytadi. ↑↓ bilan keyingi/oldingi yozuvga oʻtish mumkin.

**Isteʼmolchi beradi:** `open`, `onClose`, `size` (`sm` | `lg`), `title`, `subtitle`, `status`, `tabs?`, `children`, `actions`.
