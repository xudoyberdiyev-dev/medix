Avatar foydalanuvchini koʻrsatadi: rasm boʻlsa rasm, boʻlmasa bosh harflar.

- Bosh harflar: ism va familiyaning birinchi harflari («Dilshod Aliyev» → DA), `primary-soft` fonda `primary-button` matn (4.8:1), `600`.
- Oʻlchamlar: 24px (roʻyxat ichida), 32px (yuqori panel, sidebar), 40px (profil, izohlar).
- Doira (`radius-full`). Rasm `object-fit: cover`; yuklanmasa bosh harflarga qaytadi.
- Avatar yonida ism va lavozim yozilsa, avatar `aria-hidden`; yolgʻiz boʻlsa `alt`/`aria-label` = toʻliq ism.
- Namunadagi rasm — joy belgisi; haqiqiy foydalanuvchi rasmi bilan almashtiriladi.

**Isteʼmolchi beradi:** `name` (bosh harflar shundan olinadi), `src?`, `size` (`sm` | `md` | `lg`).
