Tooltip faqat qisqa izoh uchun: faqat-ikonka tugmaning nomi, yigʻilgan sidebar menyusi, oʻchirilgan element sababi.

- `text-primary` (toʻq) fon, oq matn, `caption` 12/16, `radius-control`, eng koʻpi 240px.
- Hover yoki klaviatura fokusida ~400ms dan keyin chiqadi, darhol yoʻqoladi; Esc yopadi.
- Ichida tugma, havola yoki muhim maʼlumot boʻlmaydi — bunday maʼlumot sahifada yoziladi.
- Element `aria-describedby` (yoki faqat-ikonka tugma uchun `aria-label`) orqali bogʻlanadi.

**Isteʼmolchi beradi:** `content`, `placement` (`top` | `right` | `bottom` | `left`), `children` (nishon element).
